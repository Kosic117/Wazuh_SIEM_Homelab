# Security Investigations

This directory documents investigations conducted using Wazuh alerts, endpoint telemetry, and system logs.

## Investigation Topics

### Windows Event Analysis
Investigation of repeated Windows Error Reporting events, device-recognition alerts, and system errors.

### Agent Queue Saturation
Analysis of Wazuh agent queue warnings, event-loss risk, disconnections, and subsequent recovery.

### Linux Kernel Vulnerabilities
Review of Wazuh vulnerability findings, affected kernel packages, available updates, and remediation status.

## Investigation Methodology

Each investigation will document:

1. Initial observation
2. Supporting evidence
3. Analysis and findings
4. Troubleshooting or remediation
5. Validation results
6. Outstanding issues

The objective is to demonstrate analytical reasoning, incident investigation, and security operations skills.
